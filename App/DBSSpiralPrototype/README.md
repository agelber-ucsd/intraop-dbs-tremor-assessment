# DBSSpiralPrototype iPad App

This folder contains the native iPadOS SwiftUI/UIKit prototype.

Open this Xcode project:

```text
DBSSpiralPrototype.xcodeproj
```

Current version: intraoperative trial recorder with guided spiral tracing, full-screen drawing mode, automated scoring, quick side-effect capture, trial history, and JSON export.

See the repository-level `README.md` for intended use, workflow, limitations, and roadmap. See `SCORING.md` for additional notes on scoring.
